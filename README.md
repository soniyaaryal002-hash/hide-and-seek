# Zone One Hide & Seek

A browser-based realtime hide-and-seek prototype for a group of friends in central London.

## Run locally

```bash
npm install
npm start
```

Then open:

```text
http://localhost:3000
```

## Features

- shared room code for multiplayer testing
- real-time room state with Socket.IO
- join room flow for players
- live player list and game status updates
- ping, catch, and panic controls

This is a local MVP for real-time playtesting with friends.
